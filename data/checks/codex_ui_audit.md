# Haq Assist UI audit

## High

- **High — Unescaped API values in HTML.** Library counts (`frontend/app.js:193`, `frontend/app.js:225`, `frontend/app.js:243`, `frontend/app.js:244`, `frontend/app.js:270`, `frontend/app.js:284`), stream counts (`frontend/app.js:412`, `frontend/app.js:415`, `frontend/app.js:447`), result region keys, references, level and snapped count (`frontend/app.js:527`, `frontend/app.js:535`, `frontend/app.js:543`, `frontend/app.js:544`, `frontend/app.js:553`, `frontend/app.js:566`) and lawyer fees (`frontend/app.js:745`) reach HTML sinks without `esc()`. Most are numbers or fixed keys in the current producers. Calling `.toLocaleString()` on a string preserves its markup, and values in quoted attributes can also break out. **Fix:** Validate payload types, escape every interpolated value at the sink, and use `textContent` for plain text.
- **High — Online search can disclose names from a legal question.** Settings promises “no names,” but the model rewrite has no de-identification check before it goes to third-party search providers (`frontend/index.html:76`, `backend/llm.py:25`, `backend/engine.py:429`, `backend/online.py:86`). **Fix:** Send only a validated, de-identified legal query, skip external search when de-identification is uncertain, and describe the disclosure accurately.
- **High — Streams can exhaust server workers and outlive their clients.** Each request starts an unbounded daemon thread and queue, and each blocking `events.get()` occupies a Starlette thread-pool slot. The ASGI event loop stays free, but enough waiting streams can starve sync routes, and disconnects leave inference running (`backend/app.py:61`, `backend/app.py:75`, `backend/app.py:77`). **Fix:** Cap concurrent inference, drive the response from an async queue, and connect disconnect and timeout signals to cooperative cancellation.
- **High — Leaving Ask can turn a completed response into an uncaught error.** After navigation `#answer` can be missing in both success and error paths. Returning home before completion can instead write or scroll a replacement view while its new Ask button looks enabled (`frontend/app.js:289`, `frontend/app.js:324`, `frontend/app.js:329`, `frontend/app.js:332`). **Fix:** Give each request ownership of its view, guard late updates, and cancel on departure or explicitly restore the in-flight UI on return.

## Medium

- **Medium — Cold startup can initialize the engine several times.** Home requests `/api/library` twice, boot calls health concurrently, and each route calls the same `lru_cache`-wrapped constructor. Concurrent cache misses can initialize duplicate indexes and models (`frontend/app.js:279`, `frontend/app.js:794`, `backend/app.py:89`, `backend/app.py:124`, `backend/app_state.py:5`, `backend/engine.py:115`). **Fix:** Share one library request and serve library counts independently of model initialization, with single initialization of the inference engine.
- **Medium — Stream lifecycle has gaps before and after reading.** The transition await runs before `try/finally`, failure leaves queued Trace events playing, and an exception in `Trace.apply()` can strand `drain()` and keep the composer busy (`frontend/app.js:292`, `frontend/app.js:297`, `frontend/app.js:319`, `frontend/app.js:330`, `frontend/app.js:377`, `frontend/app.js:495`). **Fix:** Put setup and the reader under one cleanup path, settle the playback promise on every outcome, and stop queued work and cancel/release the reader on failure.
- **Medium — Late responses can overwrite newer route or form state.** Card detail writes the global view after loading, lawyer filters can resolve out of order or after navigation, and complaint extraction and draft requests can apply stale data or label a draft with the wrong province (`frontend/app.js:643`, `frontend/app.js:692`, `frontend/app.js:708`, `frontend/app.js:736`). **Fix:** Bind callbacks to their route instance, snapshot selected inputs at dispatch, and drop superseded responses.
- **Medium — Trace state conflates library and web passes.** The engine can emit `compose` and `verify` again after the online stage, but Trace reopens earlier rows, mixes both passes, and moves the progress line backward. Early exit can leave pending rows, and a failed draft can leave a working indicator or “Haq is working” title (`frontend/app.js:371`, `frontend/app.js:385`, `frontend/app.js:415`, `frontend/app.js:445`, `frontend/app.js:479`, `frontend/app.js:495`, `backend/engine.py:427`). **Fix:** Track stage instances in event order and explicitly resolve all indicators and labels at a terminal event.
- **Medium — Pipeline preference and announcements diverge.** Switching the setting affects the next Trace only. The quiet stage has no spoken progress, while the live stage announces every stage and first hit per search, including after leaving Ask. The answer still exposes a full trace drawer when the setting is off (`frontend/app.js:161`, `frontend/app.js:295`, `frontend/app.js:405`, `frontend/app.js:419`, `frontend/app.js:435`, `frontend/app.js:571`, `frontend/index.html:100`). **Fix:** Describe when the setting applies, scope status to the Ask view, and coalesce both modes to meaningful milestones and the outcome.
- **Medium — Usage can fail to persist or overrun a downgraded quota.** With storage denied, every read recreates an unused month. An in-flight request can pass the old plan's gate and debit the new plan or next month's bucket. Tabs share storage but can start against the same remaining allowance (`frontend/app.js:10`, `frontend/app.js:91`, `frontend/app.js:103`, `frontend/app.js:289`, `frontend/app.js:325`). **Fix:** Keep an in-memory fallback, reserve against the dispatch month's demo quota, and coordinate or reconcile changes across tabs.
- **Medium — Plan changes remove keyboard focus and leave stale readouts.** Settings rebuilds its focused radio group and Plans replaces the chosen button. `/pricing` renders Plans but misses its refresh, and resetting usage refreshes only the meter (`frontend/app.js:104`, `frontend/app.js:155`, `frontend/app.js:165`, `frontend/app.js:177`, `frontend/app.js:779`). **Fix:** Update selected controls and usage in place, share refresh logic across both route aliases, and preserve or deliberately move focus after a selection.
- **Medium — Plans claims features outside the demo.** Haq Plus offers sending a case summary to a lawyer, but the recipient is fictional and the action only shows a toast. Go promises answer printing, but the explicit print action is for complaint documents. Tier “Everything in” + exclusive feature copy conflicts with the shared controls and quota-only plan switch, and “Licensed per organisation” reads as an available offering (`frontend/app.js:16`, `frontend/app.js:572`, `frontend/app.js:718`, `frontend/app.js:730`, `frontend/app.js:765`, `frontend/app.js:772`, `frontend/app.js:781`). **Fix:** Mark real referrals and organisation licensing as planned, describe current copy and print functions precisely, and present shared demo features separately from quotas.
- **Medium — Home and Trace imply every verified quote is from a PDF.** Online evidence can come from official HTML pages with no PDF page, but the hero, explainer and verified trace chip make unconditional PDF claims (`frontend/index.html:7`, `frontend/app.js:199`, `frontend/app.js:221`, `frontend/app.js:457`, `backend/online.py:217`, `backend/engine.py:441`). **Fix:** Say “official source” across modes and show PDF and page wording only for sources with those fields.
- **Medium — A default province silently overrides the location in a question.** Home says Gemma works out where the user is, but the composer always sends the selected region, initially Islamabad. The engine prefers it to the inferred region and bypasses province clarification (`frontend/app.js:38`, `frontend/app.js:224`, `frontend/app.js:289`, `backend/engine.py:395`). **Fix:** Require an explicit province choice or offer an inference option, and describe how the chosen province is used.
- **Medium — Voice replies look ready despite the planned label.** Answer and rights-card buttons offer listening without checking the configured speech capability, which requires an uninstalled model in this setup (`frontend/app.js:20`, `frontend/app.js:573`, `frontend/app.js:618`, `frontend/app.js:659`, `README.md:111`). **Fix:** Hide or label listening as planned until speech synthesis is ready, and await playback with object-URL cleanup.
- **Medium — Small and dimmed text misses AA contrast.** `--faint` is 4.02:1 on `--ink-3`; it is only 4.60:1 on solid `--ink-2`, and the 45% opacity on skipped steps further dims their labels (`frontend/styles.css:4`, `frontend/styles.css:12`, `frontend/styles.css:174`, `frontend/styles.css:221`, `frontend/styles.css:227`). **Fix:** Lighten faint text, keep skipped labels at full text opacity, and check composited gradients. [WCAG 2.2 contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- **Medium — Safe-area spacing is applied to the nav alone.** The mobile nav grows with the bottom inset, while toasts and the bottom-sheet controls use fixed offsets or padding. The sticky header and nav also omit left/right safe-area padding, and the header omits the top inset (`frontend/index.html:5`, `frontend/styles.css:496`, `frontend/styles.css:506`, `frontend/styles.css:519`, `frontend/styles.css:521`). **Fix:** Share the safe-area-adjusted nav height with content and toast offsets, and inset the sheet and edge controls appropriately.

## Low

- **Low — NDJSON EOF policy is implicit.** Newline-delimited records split across chunks and UTF-8 bytes decode correctly. The leftover buffer is dropped at EOF, so a final unterminated result reports an early end, and a partial record after a result is ignored (`frontend/app.js:303`, `frontend/app.js:310`, `frontend/app.js:319`, `backend/app.py:79`). **Fix:** Explicitly reject nonblank leftovers under the newline contract, and require exactly one terminal event.
- **Low — Dynamic links have two exceptions to the requested URL rule.** Card IDs in routes are URI-component encoded under a fixed hash prefix, while clipboard output includes the raw source URL. Rendered external `href`s use `esc(safeUrl(...))` (`frontend/app.js:540`, `frontend/app.js:563`, `frontend/app.js:583`, `frontend/app.js:633`, `frontend/app.js:655`, `frontend/app.js:658`, `frontend/app.js:715`). **Fix:** Use a shared validated internal-route builder and sanitize clipboard URLs with `safeUrl()` before copying.
- **Low — Stream serialization sits outside the error guard.** Engine exceptions are caught and mapped to generic messages, but a serialization or encoding failure can terminate the stream after headers go out (`backend/app.py:63`, `backend/app.py:77`). **Fix:** Validate and serialize events inside the guarded producer, log the exception locally, and emit a generic terminal error.
- **Low — Online retry uses mutable settings and spends another question.** A finished answer's fallback copy uses the current toggle instead of the request's setting. A library-only abstention spends a question, then its suggested online retry spends another or opens the upgrade dialog (`frontend/app.js:301`, `frontend/app.js:325`, `frontend/app.js:561`, `frontend/app.js:580`). **Fix:** Persist the request mode on the answer and surface the retry cost or treat the retry as part of the same question.
- **Low — Microphone lifecycle follows neither the route nor permission request.** Repeated clicks while permission is pending can start more than one capture, and leaving Ask can strand the recorder or let transcription overwrite a new draft (`frontend/app.js:598`, `frontend/app.js:605`, `frontend/app.js:612`). **Fix:** Lock during permission acquisition and stop the owned stream on navigation, applying transcription only to its original composer.
- **Low — Route focus can land before the relevant content.** Focus moves to an outline-free `main` after a transition, while async card content is rendered separately. A superseded transition can still reclaim focus (`frontend/app.js:179`, `frontend/app.js:643`, `frontend/styles.css:108`). **Fix:** Focus the current route's heading or a named loading target after its view commits, and scope focus to the latest navigation.
- **Low — Mobile content can clip long strings.** Pipeline chips and user/model text in grid columns lack consistent min-width and wrapping rules, with the pipeline clipped by its stage. The desktop header also keeps its full navigation down to 761 px (`frontend/styles.css:74`, `frontend/styles.css:191`, `frontend/styles.css:238`, `frontend/styles.css:285`, `frontend/styles.css:309`, `frontend/styles.css:496`). **Fix:** Use `minmax(0, 1fr)` or `min-inline-size: 0`, allow long tokens to break, and switch nav layout before desktop controls run out of room.
- **Low — Reduced motion misses a few transitions and live OS changes.** With OS reduction alone, the progress line scales and switch knob slides. The animated logo is only refreshed when the setting is applied or the view renders (`frontend/app.js:49`, `frontend/app.js:171`, `frontend/styles.css:149`, `frontend/styles.css:213`, `frontend/styles.css:479`). **Fix:** Disable nonessential movement for both preference sources and listen for OS preference changes to swap the logo immediately.
- **Low — Trace updates force layout during playback.** `add()` appends markup, then `follow()` immediately reads scroll geometry and can restart a smooth scroll for each insertion. The CSS motion mostly uses transforms and opacity, with shadows and blur requiring paint (`frontend/app.js:396`, `frontend/app.js:397`, `frontend/styles.css:184`, `frontend/styles.css:438`). **Fix:** Batch event DOM writes and schedule at most one panel scroll per animation frame.
- **Low — Dialog fallback and Settings feedback need attention.** Native dialogs have names and focusable close buttons. The fallback probes forced styles on each manual close, and a global toast can sit behind the open modal's top layer (`frontend/index.html:65`, `frontend/index.html:98`, `frontend/app.js:110`, `frontend/app.js:165`, `frontend/styles.css:458`). **Fix:** Cache feature detection, make closing idempotent, and put Settings feedback in a local status region inside the dialog.
- **Low — Startup can claim the model is ready before health is known.** A missing health response is treated as “Gemma 4 ready,” while the footer may say offline (`frontend/app.js:269`, `frontend/app.js:794`). **Fix:** Show checking or unknown until verified.
- **Low — The home evaluation claim lacks a defined measure.** “0 unverifiable citations” has no sample or result link. The 40-question holdout reports expected-law accuracy separately, with correct laws cited in 19 of 32 answerable cases (`frontend/app.js:246`, `eval/results/everyday_holdout.md:5`). **Fix:** Link the matching run and define quote provenance separately from whether the cited law answers the question.
- **Low — The flow line animates along the wrong axis on narrow screens.** The layout changes the connector to vertical, while its animation continues to scale horizontally (`frontend/styles.css:348`, `frontend/styles.css:351`, `frontend/styles.css:490`). **Fix:** Use a vertical scale animation at the stacked breakpoint or keep that connector static.

## Verified checks

- `node --check frontend/app.js` passed. A Node fixture using the actual Ask handler confirmed byte-by-byte UTF-8 NDJSON, the same-view duplicate guard, the unterminated-result error, the off-route rejection and the storage-denied counter reset.
- FastAPI via `httpx.ASGITransport`, with a stub inference engine and real statute rows, returned a newline-terminated progress/result sequence, a generic terminal error on a raised exception, and a library of 4,716 sections across 54 acts and 32 areas. `/` returned 200. Live inference and external voice/search services were outside these fixture checks.
- `#q` has an explicit hidden label and `#region` has a wrapping label with hidden text. Switches have native checkbox state, `role="switch"`, labels and descriptions. Composer handles Enter, Shift+Enter and `isComposing`. Urdu text has language markup and RTL CSS, and free-text fields use `dir="auto"` (`frontend/app.js:201`, `frontend/app.js:257`, `frontend/index.html:33`, `frontend/index.html:71`, `frontend/styles.css:65`).
- Dialog entry and exit CSS uses `@starting-style`, `allow-discrete`, `display` and `overlay`. The three `haq-logo` selectors belong to mutually exclusive stage states, and the replay drawer removes its temporary header before insertion. Both scroll-driven animations are gated by feature support and the OS motion preference (`frontend/styles.css:198`, `frontend/styles.css:205`, `frontend/styles.css:280`, `frontend/styles.css:346`, `frontend/styles.css:373`, `frontend/styles.css:438`, `frontend/app.js:357`, `frontend/app.js:512`). [Chrome guidance on top-layer transitions](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-behaviors/animate-to-from-top-layer)
- At 360 px the CSS selects a fixed bottom nav, wrapping composer controls, and single-column plans and complaint layouts (`frontend/styles.css:175`, `frontend/styles.css:494`, `frontend/styles.css:496`). Headless Edge failed to return a rendered fixture in this environment, so mobile geometry, real IME behavior and assistive-technology announcements were assessed from source.
