# The 54 acts in Haq Assist's library

Generated from `data/manifest.json`, `data/scope.json` and `data/sections.jsonl`. **54 acts, 4,716 sections, from 57 downloaded PDFs** (3 excluded, listed at the end).

Every PDF comes from one of five official portals. Punjab, Sindh and KP use `.gov.pk`; only Balochistan uses `.gob.pk`:

| Portal | Host |
|---|---|
| Pakistan Code (federal and Islamabad) | pakistancode.gov.pk |
| Punjab Code | punjabcode.punjab.gov.pk |
| Sindh Laws | sindhlaws.gov.pk |
| KP Code | kpcode.kp.gov.pk |
| Balochistan Code | balochistancode.gob.pk |

Some acts appear under more than one province. For example, the Provincial Motor Vehicles Ordinance 1965 and the 2010 workplace-harassment Act each have their own provincial copy, with that province's amendments.
